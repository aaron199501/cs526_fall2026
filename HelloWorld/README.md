CS526 Week 1 Coding Assignment
HelloWorld

Implementation:

This program is written in Python. It reads input from standard input using sys.stdin. The program reads the input file line by line and prints each line to standard output.

The program can accept a file containing any number of lines and print all of the lines to standard output.


How to Run:

1. Open a command-line terminal.

2. Navigate to the HelloWorld project directory.

3. Run the program using the following command:

python helloworld.py < myfile


Sample Input:

Hello from David Mellor


Sample Output:

Hello from David Mellor
